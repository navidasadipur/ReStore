# پرامپت‌های پیاده‌سازی بازطراحی ReStore

پرامپت‌ها را از بالا به پایین، یکی‌یکی در چتی با ریشه همین مخزن اجرا کن.
پرامپت ۱ و ۲ با هم نمونه اولیه را می‌سازند. رنگ و خوانایی هدر و کارت را روی
موبایل و دسکتاپ بررسی کن و بعد سراغ کاتالوگ برو. مبنای همه مراحل
[پلن بازطراحی فروشگاه](storefront-redesign-plan.md) و [دستورهای پروژه](../AGENTS.md) است.

## ۱. تم فارسی و راست‌چین MUI

```text
مرحله اول بازطراحی ReStore را اجرا کن. ابتدا AGENTS.md و docs/storefront-redesign-plan.md را بخوان.

با نسخه فعلی MUI و Emotion کار کن. تم را از client/src/app/layout/App.tsx به ماژول مشترک منتقل کن و رنگ‌ها، تایپوگرافی، فاصله‌ها، شعاع گوشه‌ها و حالت focus را در همان تم تعریف کن. برای نمونه اولیه از سبز تیره #224938، زمینه #F8F8F5 و کارت سفید استفاده کن. قرمز ملایم برای نشان تخفیف آینده است.

زبان فارسی و راست‌چین را در پوسته فروشگاه و تم MUI تنظیم کن. سازگاری Emotion و جهت پنجره‌های بازشو را بررسی کن. از فونت فارسی محلی دارای مجوز استفاده کن و اگر فونت مناسبی در دسترس نیست، برای نمونه یک فهرست جایگزین خوانا بگذار و محدودیت را گزارش کن. اگر کنترل تم تیره در پوسته فعلی هست، کارکردش را حفظ کن.

این برش را به تم و پوسته محدود کن. هدر فعلی، یکی از فرم‌ها، سبد و منوی بازشو را از نظر تغییر جهت و نمایش متن ترکیبی فارسی و انگلیسی بررسی کن. بررسی‌های متناسب با تغییر را طبق بخش Build and verify در README اجرا کن. در پایان انتخاب‌های رنگ و فونت و نتیجه بررسی را گزارش کن.
```

## ۲. هدر و کارت محصول با داده واقعی

```text
پس از آماده شدن تم راست‌چین، برش هدر و کارت محصول ReStore را اجرا کن. AGENTS.md، بخش Selected design در docs/storefront-redesign-plan.md و کد فعلی Header، ProductCard و کاتالوگ را بخوان.

هدر طرح الهام‌گرفته از اسنپ‌شاپ را با برند ReStore، جست‌وجوی فارسی، ورود یا حساب کاربری و تعداد اقلام سبد بساز. روی موبایل برای جست‌وجو ردیفی مستقل بگذار. ارسال جست‌وجو باید به /catalog برود و از جست‌وجوی موجود API استفاده کند. رفتار ورود، سبد و مسیر مدیریت را با مجوزهای فعلی حفظ کن.

در مسیر واقعی کاتالوگ از کارت جدید استفاده کن. عکس، نام، قیمت و پیوند جزئیات را از داده محصول بگیر. افزودن به سبد و وضعیت انتظار را به جریان فعلی وصل کن. قیمت API ریال است. نمایش تومان را با currencyFormat فعلی انجام بده. قیمت قبلی و درصد تخفیف زمانی وارد UI می‌شوند که داده واقعی‌شان در API موجود باشد.

هدر و کارت نمایشی باید داده، href و callback تایپ‌شده بگیرند و بدون Router یا Redux قابل رندر باشند. انتخاب داده، dispatch، ناوبری و دریافت API در لایه صفحه بمانند. نمونه را با داده واقعی در حدود 390 و 1440 پیکسل، نام بلند محصول، جست‌وجو و افزودن به سبد بررسی کن. چیدمان کامل کاتالوگ در پرامپت بعدی انجام می‌شود. نتیجه خوانایی و رنگ را برای تصمیم قبل از ادامه گزارش کن.
```

## ۳. کاتالوگ و فیلترها

```text
صفحه کاتالوگ ReStore را با تم و کارت تاییدشده بازطراحی کن. ابتدا AGENTS.md، docs/storefront-redesign-plan.md و بخش Catalog از docs/api-contracts.md را بخوان.

شبکه محصول را برای دو ستون در عرض رایج موبایل و ستون‌های بیشتر در دسکتاپ تنظیم کن. در موبایل فیلتر برند و نوع را در پنل بازشو و در دسکتاپ در نوار کناری نشان بده. از مدل فیلتر، مرتب‌سازی، صفحه‌بندی و adapter فعلی API استفاده کن. پارامتر جست‌وجوی API fullSearchPhrase است. با تغییر عبارت جست‌وجو یا فیلتر، شماره صفحه به یک برگردد. پس از بستن پنل، focus به دکمه فیلتر برگردد و Escape آن را ببندد.

حالت دریافت، نتیجه خالی، خطا و تلاش مجدد را پوشش بده. کامپوننت فیلتر و نمای شبکه مستقل از Router و Redux باشند. جست‌وجو از هدر، ترکیب برند و نوع، مرتب‌سازی، صفحه‌بندی و ورود به جزئیات را با داده واقعی روی موبایل و دسکتاپ بررسی کن. بررسی‌های کلاینت مرتبط را از README اجرا و نتیجه را گزارش کن.
```

## ۴. جزئیات محصول و افزودن به سبد

```text
صفحه جزئیات محصول را بر اساس طرح منتخب ReStore اجرا کن. AGENTS.md و docs/storefront-redesign-plan.md را بخوان و مسیر فعلی /catalog/:id و جریان سبد را بررسی کن.

عکس، نام، توضیح، قیمت تومان و وضعیت موجودی را با سلسله‌مراتب روشن نشان بده. قیمت و موجودی را نزدیک دکمه خرید بگذار. خرید را برای محصول ناموجود غیرفعال کن و بارگیری، محصول یافت‌نشده، عکس جایگزین و خطای قابل تلاش مجدد را با قرارداد فعلی پوشش بده. رفتار فعلی سبد و تغییر تعداد را حفظ کن. داده‌ها، href و عملیات را از لایه صفحه به نمای مستقل از Router و Redux بده.

ورود مستقیم به آدرس محصول و ورود از کارت، محصول موجود و ناموجود و افزودن به سبد مهمان را بررسی کن. از قیمت و موجودی API استفاده کن. بررسی‌های متناسب کلاینت را طبق README اجرا کن و نتیجه را گزارش کن.
```

## ۵. صفحه خانه

```text
صفحه خانه ReStore را با اجزای مشترک MUI و طرح منتخب بساز. ابتدا AGENTS.md، docs/storefront-redesign-plan.md و کد HomePage فعلی را بخوان.

محتوای دمو و اسلایدر چرخان را با میان‌برهای تصویری دسته‌ها، یک بنر جمع‌وجور و بخش «محصولات منتخب» جایگزین کن. میان‌برها بالای بنر باشند و به کاتالوگ با نوع محصول مربوط وصل شوند. نوع‌ها را از فیلترهای موجود API بگیر و برای نام فارسی دسته‌ها از نگاشت نمایشی استفاده کن. بخش محصولات منتخب را با محصولات واقعی و کارت مشترک بساز. از عنوان تخفیف و پرفروش‌ترین فقط وقتی استفاده کن که کاتالوگ داده معتبر مربوط را دارد.

برای تصاویر از دارایی‌های پروژه استفاده کن، فضای تصویر را قبل از بارگیری مشخص کن و تصاویر زیر محدوده اول صفحه را در صورت مناسب بودن تنبل بارگیری کن. نماهای خانه ورودی تایپ‌شده بگیرند. مسیر خانه تا دسته و تا جزئیات محصول، حالت داده خالی و چیدمان موبایل و دسکتاپ را بررسی کن. نتیجه و بررسی‌های کلاینت را گزارش کن.
```

## ۶. بررسی کل فروشگاه پیش از انتشار

```text
نسخه بازطراحی‌شده ReStore را با معیارهای docs/storefront-redesign-plan.md بررسی کن و اشکال‌های ناشی از همین بازطراحی را در محدوده آن اصلاح کن.

در حدود 390 و 1440 پیکسل، مسیر خانه، جست‌وجو یا دسته، فیلتر، صفحه‌بندی، جزئیات و افزودن به سبد را با داده واقعی طی کن. نمایش ریال به تومان، نام بلند و متن آمیخته فارسی و انگلیسی، تصویر ناموجود، کنتراست، focus و کار با کیبورد را بررسی کن. دسترسی حساب و مدیریت، سبد مهمان و مسیر پرداخت موجود را از نظر regression بررسی کن. پرداخت فقط با Sandbox انجام شود و اگر محیط آن فراهم نیست، وضعیت را گزارش کن.

طبق README بررسی TypeScript، تست‌های کلاینت و بیلد ایزوله را اجرا کن. مقصد بیلد را client/build نگه دار تا خروجی داخل wwwroot وارد تغییرات سورس نشود. گزارش را با موارد تاییدشده، موارد بررسی‌نشده و اشکال‌های باقی‌مانده تمام کن. سئو و Next.js موضوع فاز بعدی‌اند.
```
